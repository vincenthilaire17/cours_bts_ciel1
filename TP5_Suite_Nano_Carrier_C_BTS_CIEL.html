0.1 Le Cœur de Calcul : Brochage de l'Arduino Nano v3 (ATmega328P)

Contrairement au Raspberry Pi Pico (RP2040 en logique 3,3 V), l'Arduino Nano fonctionne en logique pure 5 V (TTL). Il dispose d'un microcontrôleur 8 bits ATmega328P cadencé à 16 MHz, intégrant 32 Ko de mémoire Flash, 2 Ko de SRAM et 1 Ko d'EEPROM.

Figure 0.1 — Brochage officiel complet de l'Arduino Nano v3 (Datasheet Officielle Arduino A000005) : Multiplexage E/S, Timers PWM (OC1A/B sur D9/D10, OC2A/B sur D11/D3, OC0A/B sur D6/D5), CAN 10 bits (ADC0–ADC7), Interrupts (INT0/INT1, PCINT) et bus de communication (UART, I2C, SPI).

0.2 La Carte d'Extension Officielle : Arduino Nano Connector Carrier (Datasheet ASX00051)

Pour sécuriser le câblage et standardiser les interconnexions, l'Arduino Nano s'enfiche directement au centre du Nano Connector Carrier officiel d'Arduino (SKU ASX00051). Ce carrier industriel développe la connectivité de la famille Nano en combinant une face supérieure (TOP) à connecteurs Nano femelles et une face inférieure (BOTTOM) équipée de connecteurs Grove et QWIIC, ainsi que d'un lecteur de carte Micro SD pour l'enregistrement de données.

Figure 0.2 — Brochage officiel de l'Arduino Nano Connector Carrier (Datasheet ASX00051) : Vues TOP (headers Nano JP1/JP2 & switch de tension) et BOTTOM (connecteurs Grove J4 à J7, QWIIC et lecteur MicroSD).

⚡ Règle Impérative de Configuration : Le Commutateur « 5V - 3V3 »

Sur la face supérieure (TOP), à gauche des connecteurs femelles du Nano, se trouve le sélecteur d'alimentation :
« Set the board selector switch to match your Nano board GPIO voltage ».
L'Arduino Nano v3 (ATmega328P) fonctionnant en logique pure 5 V, vous DEVEZ positionner ce commutateur sur « 5V » ! Cette configuration garantit que la broche VCC de l'ensemble des connecteurs Grove délivre bien les 5,0 V indispensables au potentiomètre Grove, à la LED Bar et au relais.

Affectation des Connecteurs Grove en Face Inférieure (BOTTOM) :

  • Connecteur Grove (J7) — Entrées A0 / A1 : Broche 1 = A0 | Broche 2 = A1 | Broche 3 = VCC (5V) | Broche 4 = GND.
    ➜ C'est sur ce port Grove J7 que vous brancherez directement le Potentiomètre 10 kΩ !
  • Connecteur Grove (J5) — Entrées A2 / A3 : Broche 1 = GND | Broche 2 = VCC | Broche 3 = A3 | Broche 4 = A2.
  • Connecteur Grove (J6) — Bus I2C : Broche 1 = SCL (A5) | Broche 2 = SDA (A4) | Broche 3 = VCC | Broche 4 = GND.
  • Connecteur Grove (J4) — Liaison Série UART : Broche 1 = GND | Broche 2 = VCC | Broche 3 = TX (D1) | Broche 4 = RX (D0).
  • Connecteur QWIIC : Interface I2C miniature 3,3 V (SCL, SDA, +3V3 OUT, GND).

PARTIE 1 : Notions de Fonctions en C++ & Mesure Analogique Calibrée 45 min

1.1 Pourquoi Découper un Logiciel Embarqué en Fonctions ?

En programmation professionnelle, un code contenu exclusivement dans une boucle void loop() de 200 lignes est une source majeure de bogues, impossible à maintenir, à tester unitairement ou à réutiliser. Une fonction est un sous-programme autonome qui réalise une tâche précise.

Composant de la Fonction Rôle & Syntaxe en C++ Exemple Appliqué au TP
Type de Retour Définit la nature de la valeur renvoyée. Utilisez void si la fonction n'a rien à renvoyer (procédure d'action). float pour une tension en Volts,
uint8_t pour un niveau (0 à 10),
void pour initialiser le matériel.
Identificateur Nom verbeux décrivant l'action sans ambiguïté (convention camelCase). lireConsignePotentiometre(),
afficherBargraphe().
Paramètres Formels Données transmises par l'appelant entre parenthèses, avec leur type strict. (uint8_t niveau),
(float tensionVolts).
Corps de la Fonction Bloc d'instructions délimité par des accolades { ... } avec l'instruction return si le type n'est pas void. return (codeBrut / 1023.0f) * 5.0f;

1.2 Concept Fondamental : Passage par Valeur vs Passage par Référence (&)

En C/C++, il existe deux façons de transmettre une variable à une fonction :

  • Passage par Valeur (copie locale) : La fonction crée un clone de la variable en mémoire. Les modifications faites dans la fonction n'impactent pas l'original dans l'appelant.
  • Passage par Référence (&) : La fonction reçoit l'adresse de la variable originale. Toute modification faite à travers cette référence altère directement la variable d'origine ! C'est l'outil parfait pour renvoyer plusieurs grandeurs calculées (ex: renvoyer la tension flottante tout en modifiant le code CAN brut).
// Exemple : La fonction renvoie la tension (float) ET modifie la variable codeCanBrut via sa référence '&'
float lireConsignePotentiometre(uint16_t &codeCanBrut) {
    codeCanBrut = analogRead(PIN_POT_CONSIGNE); // 0 à 1023
    float tension = (codeCanBrut / 1023.0f) * 5.00f;
    return tension; // Retour scalaire
}

PARTIE 2 : Pilotage Dynamique de l'Afficheur Grove - LED Bar (MY9221) 40 min

2.1 Présentation & Câblage du Bargraphe 10 Segments

Le module Grove - LED Bar remplace avantageusement 10 LEDs discrètes et leurs 10 résistances sur breadboard. Il se compose de :

  • 1 segment Rouge (LED 10 : alerte / puissance maxi),
  • 1 segment Orange (LED 9),
  • 1 segment Jaune (LED 8),
  • 7 segments Verts (LEDs 1 à 7 : vitesse modérée / nominale).
Figure 2.1 — Brochage, organisation des couleurs et interface série du module Grove - LED Bar v2.0 (driver MY9221).

⚠️ Raccordement de la Grove - LED Bar sur le Carrier Nano

Le connecteur numérique supérieur JP2 du Nano Connector Carrier distribue directement les broches du microcontrôleur. Raccordez le module Grove - LED Bar aux broches de l'Arduino Nano à l'aide d'un câble d'adaptation :

  • Fil Jaune de la LED Bar (Pin 3 : DCKI / Clock) ➜ Relié à la broche D7 (Broche 10 de JP2).
  • Fil Blanc de la LED Bar (Pin 4 : DI / Data) ➜ Relié à la broche D6 (Broche 9 de JP2).
  • Fil Rouge (Pin 2 : VCC 5V) ➜ Relié à la broche +5V (Broche 12 de JP1).
  • Fil Noir (Pin 1 : GND) ➜ Relié à la masse GND (Broche 14 de JP1 ou 4 de JP2).

L'instanciation de l'objet dans votre code C++ est donc parfaitement claire :
Grove_LED_Bar bar(7, 6, 0, LED_BAR_10); // Broche 7 = Clock (DCKI), Broche 6 = Data (DI)

2.2 Écriture des Fonctions de Conversion et d'Affichage

Pour respecter le principe de modularité, nous écrivons deux fonctions distinctes : une fonction mathématique pure (qui convertit la tension en niveau de 0 à 10) et une fonction d'action (qui met à jour la LED Bar) : 

// --- FONCTION 1 : CONVERSION MATHÉMATIQUE SÉCURISÉE ---
uint8_t convertirTensionEnNiveau(float tensionVolts) {
    // Zone morte basse pour garantir l'arrêt total en butée
    if (tensionVolts < 0.15f) {
        return 0;
    }
    if (tensionVolts >= 4.90f) {
        return 10;
    }
    // Échelonnement proportionnel en 10 crans réguliers de 0,5 V
    uint8_t niveau = (uint8_t)((tensionVolts / 5.0f) * 10.0f + 0.5f);
    if (niveau > 10) niveau = 10;
    return niveau;
}

// --- FONCTION 2 : PILOTAGE MATÉRIEL DU DRIVER MY9221 ---
void afficherBargraphe(uint8_t niveau) {
    bar.setLevel(niveau); // 0 = éteint, 1 à 10 = nombre de segments illuminés
}

PARTIE 3 : Chaîne de Puissance Hybride — Relais de Sécurité & PWM Transistor 45 min

3.1 Le Schéma d'Architecture Hybride : Reprise du TP 5 sur Nano Carrier

Nous réinvestissons l'étage de puissance validé au TP 5. La Powerbank Varta 5 V alimente le moteur CC via deux étages complémentaires :

  1. Contacteur de ligne par Relais Grove (Broche D2 / JP2:5) : Assure l'isolation galvanique. Si le potentiomètre est à zéro (Niveau = 0), le relais s'ouvre : aucun courant résiduel ne peut circuler vers le moteur, garantissant une sécurité mécanique totale.
  2. Hacheur Série par Transistor TIP31C (Broche D9 PWM) : Dès que le niveau dépasse 0, le relais se ferme et la broche D9 module le rapport cyclique α (Timer 1 de l'ATmega328P, fréquence 490 Hz, 8 bits : 0 à 255).
  3. Diode de Roue Libre 1N4001 : Protège impérativement le transistor des surtensions inductives d'ouverture (uL = L · didt).
Figure 3.1 — Synoptique d'interconnexion globale : Nano Carrier, capteurs Grove, afficheur MY9221 et chaîne de puissance Varta.

⚡ Règle d'Or de Câblage Puissance : La Masse Commune

La Powerbank Varta alimente le moteur en 5 V via le contact du relais. Pour que la commande PWM de la broche D9 puisse polariser la base du transistor TIP31C, la borne GND (0 V) de l'Arduino Nano DOIT être impérativement reliée à l'Émetteur du transistor TIP31C et au pôle négatif (-) de la Powerbank !

3.2 Écriture de la Fonction de Commande de Puissance

// --- FONCTION DE COMMANDE HYBRIDE AVEC DEUX RETOURS PAR RÉFÉRENCE ---
void commanderEtagePuissance(uint8_t niveau, bool &etatRelais, uint8_t &valeurPwm) {
    if (niveau == 0) {
        // --- ARRÊT COMPLET DE SÉCURITÉ ---
        valeurPwm = 0;
        analogWrite(PIN_PWM_MOTEUR, 0);   // Transistor bloqué
        
        etatRelais = false;
        digitalWrite(PIN_RELAIS, LOW);    // Relais ouvert (coupure physique)
        digitalWrite(PIN_LED_ETAT, LOW);  // Témoin éteint
    } 
    else {
        // --- MARCHE ACTIVE ---
        etatRelais = true;
        digitalWrite(PIN_RELAIS, HIGH);   // Relais fermé (+5V Varta établi)
        digitalWrite(PIN_LED_ETAT, HIGH); // Témoin allumé

        // Échelonnement PWM de 70 (seuil de décollage moteur) à 255 (100 %)
        valeurPwm = (uint8_t)map(niveau, 1, 10, 70, 255);
        analogWrite(PIN_PWM_MOTEUR, valeurPwm);
    }
}

PARTIE 4 : Synthèse Modulaire, Télémétrie Série & Évaluation 25 min

4.1 Code Complet Intégré : sketch_nano_drivecarrier.ino

Admirez la clarté et l'élégance de la fonction void loop() finale : elle tient en seulement 5 lignes d'appels de fonctions ! Chaque bloc technique est encapsulé, lisible et testable unitairement : 

// ==============================================================================
// TP 5 bis : NANO-DRIVECARRIER — BTS CIEL 1re Année (Option B)
// Cible : Arduino Nano v3 sur Arduino Nano Connector Carrier (ASX00051)
// ==============================================================================
#include <Arduino.h>
#include <Grove_LED_Bar.h>

const uint8_t PIN_RELAIS       = 2;
const uint8_t PIN_LED_ETAT     = 4;
const uint8_t PIN_PWM_MOTEUR   = 9;
const uint8_t PIN_POT_CONSIGNE = A0;

// Connexions Carrier : D7 = Clock (Jaune), D6 = Data (Blanc)
Grove_LED_Bar bar(7, 6, 0, LED_BAR_10);

void setup() {
    initialiserMateriel();
    animationAccueilChenillard();
}

void loop() {
    static uint32_t dateDerniereTelemetrie = 0;
    uint16_t codeCan = 0;
    bool relaisEnclenche = false;
    uint8_t commandePwm = 0;

    // 1. Acquisition consigne analogique (Passage par référence)
    float tension = lireConsignePotentiometre(codeCan);

    // 2. Conversion mathématique en niveau discret (0 à 10)
    uint8_t niveau = convertirTensionEnNiveau(tension);

    // 3. Mise à jour de l'afficheur dynamique (Grove - LED Bar)
    afficherBargraphe(niveau);

    // 4. Pilotage puissance (Relais de sécurité + PWM TIP31C)
    commanderEtagePuissance(niveau, relaisEnclenche, commandePwm);

    // 5. Télémétrie périodique non-bloquante (115200 bauds)
    if (millis() - dateDerniereTelemetrie >= 250) {
        dateDerniereTelemetrie = millis();
        envoyerTelemetrieSerie(tension, codeCan, niveau, relaisEnclenche, commandePwm);
    }
}
